# Graphics Designer Portfolio

A modern, professional portfolio website showcasing graphic design work and services. This portfolio features all essential elements expected from a contemporary graphics designer's online presence.

## Features

### Modern Design Elements
- **Responsive Design**: Fully responsive layout that works seamlessly across all devices (desktop, tablet, mobile)
- **Hero Section**: Eye-catching hero with animated gradient visual element and call-to-action buttons
- **Smooth Animations**: CSS animations and transitions for enhanced user experience
- **Modern Typography**: Google Fonts integration (Poppins, Playfair Display)

### Portfolio Showcase
- **Filterable Grid**: Interactive portfolio grid with category filters (All, Branding, Web Design, Print, Illustration)
- **Hover Effects**: Smooth hover animations and overlay effects on portfolio items
- **Project Cards**: Professional project cards with images, descriptions, and tags

### Professional Sections
- **About Section**: Personal introduction with statistics counter and skills showcase
- **Services Section**: Clear presentation of offered services with feature lists
- **Testimonials Slider**: Rotating client testimonials with navigation controls
- **Contact Form**: Functional contact form with validation and success message
- **Social Media Integration**: Links to professional platforms (Behance, Dribbble, Instagram, LinkedIn, Twitter)

### User Experience Features
- **Sticky Navigation**: Fixed navigation bar with smooth scroll behavior
- **Mobile Menu**: Hamburger menu for mobile devices
- **Active Link Highlighting**: Navigation links highlight based on scroll position
- **Scroll Animations**: Elements fade in as users scroll through the page
- **Lazy Loading Ready**: Structure supports lazy loading for optimized performance

### Technical Features
- **Clean HTML5**: Semantic HTML structure
- **Modern CSS3**: Flexbox and Grid layouts, CSS custom properties
- **Vanilla JavaScript**: No framework dependencies, lightweight and fast
- **SEO Optimized**: Meta tags, semantic structure, and accessibility features
- **Font Awesome Icons**: Professional icon set integration
- **Cross-browser Compatible**: Works on all modern browsers

## Usage

Simply open `index.html` in a web browser to view the portfolio. No build process or dependencies required.

### Customization

1. **Content**: Update text content in `index.html`
2. **Colors**: Modify CSS custom properties in `styles.css` `:root` section
3. **Images**: Replace placeholder gradients with actual project images
4. **Contact Info**: Update email, phone, and location in the contact section
5. **Social Links**: Add your social media profile URLs
